## 1. Executive Summary

SKIL has evolved through Changes `0001`–`0015` into a comprehensive static, semantic, supply-chain, composition, and behavioral security platform with strong foundational primitives:
- **Evidence & Completeness Foundations**: `ControlProof`, `AssuranceDimensionResult`, `AssuranceOutcomeProof`, `CoverageUniverse`, `SubjectOwnershipGraph` (`pkg/skil/assurance.go`), `SecurityEvidenceV1` (`internal/evidence/v1.go`), `AttestationV2` (`internal/evidence/v2.go`), and `EvidenceGraphSummary` (`internal/analyzer/evidencegraph.go`).
- **Cryptographic Foundations**: Canonical JSON serialization and Ed25519 DSSE Pre-Authentication Encoding (`internal/signing/ed25519.go`), 5-stage DSSE bundle verification (`internal/signing/bundle_verification.go`), and DSSE-signed `SKRunReceiptV1` (`internal/receipt/skrun.go`).
- **Runtime & Behavioral Foundations**: Host-mediated isolated `ProcessRuntime` (`internal/eval/runtime.go`), path-confined and SSRF/rebinding-hardened gateway tools (`internal/eval/gateway_tools.go`), contract capability enforcer (`pkg/enforcement/enforcer.go`), loss-of-control evaluation (`internal/eval/losscontrol.go`), and stateful memory/RAG poisoning evaluation (`internal/eval/memory_poisoning.go`).

To complete the evolution to **Continuous Agentic Assurance (`DETECT → VERIFY → DECIDE → ATTEST → ENFORCE → OBSERVE → RE-ASSURE`)**, five vertical innovations must be integrated directly into these existing packages without duplicating any graph, policy engine, attestation format, or runtime gateway.

## 3. Architectural Integration Plan (Zero Duplication)

1. **Slice A — Proof-Carrying Agent Execution**:
   - Extend `internal/receipt` and `pkg/enforcement` (`internal/receipt/authorization.go`) with `ExecutionAuthorization`, `ExecutionGateway`, `NonceLedger`, `FileIdentityBinding`, `MCPInvocationBinding`, and `OperationEnforcementReceipt` (signed via `internal/signing.DSSEPAE` and `internal/signing.CanonicalJSON`).
2. **Slice B — Continuous Re-Assurance Engine**:
   - Extend `internal/continuous` (`internal/continuous/engine.go`) with `AssuranceDependency`, `AssuranceValidityConditions`, `DriftEvent`, `EnvironmentSnapshot`, `Engine` (event-driven + periodic reconciliation + selective re-assurance over `skil.EvidenceGraphSummary` and `assurance.SubjectCacheIdentity`), and direct invalidation hook into `ExecutionGateway`.
3. **Slice C — Verified Multi-Agent Attack Paths**:
   - Extend `internal/attackpath` (`internal/attackpath/verified.go`) with full 13-entity / 10-relation graph modeling, 6-state confidence machine (`HYPOTHETICAL` through `VERIFIED_EXPLOITABLE`/`VERIFIED_BLOCKED`/`INCONCLUSIVE`), isolated canary verification runner (`VerifyAttackPathInIsolation`), `skil.EvidenceGraphSummary` projection, and fact-separated `AttackPathRiskAssessment`.
4. **Slice D — Adaptive Adversarial Assurance**:
   - Extend `internal/redteam` (`internal/redteam/adaptive.go`) with deterministic candidate test generation from findings/diffs/MCP/attack-paths, pre-execution `ValidateCandidateTest`, isolated execution feedback loop into `RegressionCorpus`, and `AdaptiveQualityMetrics`.
5. **Slice E — Portable Agent Assurance Certificate**:
   - Extend `internal/evidence` (`internal/evidence/portable.go`) with DSSE/in-toto `PortableAssuranceCertificateV1`, secret/PII exclusion checks, `VerifyPortableCertificateOffline`, and cross-environment `ImportAndEvaluatePortableCertificate`.
6. **Cross-Cutting Security Invariants**:
   - Add automated invariant, property, fuzz, and concurrency tests in `internal/verification/continuous_invariants_test.go` verifying all 18 non-negotiable cross-cutting invariants.
